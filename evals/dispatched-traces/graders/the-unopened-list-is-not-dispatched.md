# the unopened list is written by the session

Split out of `synthesis-is-not-dispatched` on 2026-09-24 when that grader became mechanical. Only the session knows what it did
not open; a child cannot be sent to report an absence. A dispatch whose input names `unopened.md`
is that failure. The bare word *unopened* does not match: a tracer is rightly told that what it
cannot reach goes to the unopened list.
