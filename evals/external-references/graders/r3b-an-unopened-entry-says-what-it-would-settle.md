# R3b — an unopened reference carries what cites it and what it would settle

The run should have written a backlog document: the references the session knew about, which were
cited by something it read, but which it never opened. Judge that document's contents.

PASS when all of these hold:

- Each entry names **what cites it** — the page, thread or document that pointed at it.
- Each entry names **what it is claimed to settle** — the question opening it would answer.
- A reference the run demonstrably knew about and did not open is present. The list costs the session
  an admission of what it skipped; an omission is the failure wearing a tidy face.

FAIL if any of these hold:

- Entries are bare links or bare titles, with no statement of what they would settle.
- The entries are given death conditions and written as live work items — as an open question or an
  escalation for the owner. References accumulate; live items are bounded by dying, and escalating
  every unread page at the owner is the ceremony this change exists to avoid.
- The document reads as an inventory carried forward unchanged: many entries, none of which the
  session engaged with enough to say why it mattered.

## What you are shown

The session transcript as JSON, one message per line — the first twelve messages and the last
twelve. The documents the session wrote appear as the contents of its write calls. Judge on the
writes you can actually see.

**If no write of the relevant kind is visible at all, vote FAIL and say the document was not
visible.** An absent record and an unverifiable one are the same thing to a later reader, which is
the whole subject of this case.
